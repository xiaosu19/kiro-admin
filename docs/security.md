# 权限与数据边界

本系统以平台用户为业务归属边界。一个 AWS 母号可以授权给多个子用户；共享母号不表示共享其 SSO 用户、分组、密码或任务结果。

| 内容 | 普通子用户 | 管理员 |
| --- | --- | --- |
| AWS 账号 | 查看已绑定账号的必要信息，不能读取访问密钥 | 管理账号配置、绑定和凭据 |
| SOCKS5 代理 | 使用绑定母号的代理，不读取代理认证 | 管理代理及绑定 |
| SSO / 分组 | 管理本人创建的记录 | 管理全站业务记录 |
| 创建 / 订阅 / 删除批次 | 本人批次；提交与后台执行均检查绑定和记录权限 | 按管理权限处理业务记录 |
| 登录信息 CSV / TXT | 只包含本人有权导出的记录 | 按管理权限导出业务凭据 |
| 认证 / 改密批次 | 只查看和操作本人发起的任务 | 只能操作本人发起的认证任务 |
| 验证码 / 粘贴转换 / Token 下载 | 仅任务发起人 | 仅任务发起人 |
| AI 地址、模型与密钥 | 本人配置和本人调用 | 本人配置和本人调用，不能借用其他用户密钥 |

管理员可以针对有权管理的 SSO 另行发起任务；该新任务归管理员，并使用管理员自己的 AI 服务。不会接管子用户已有认证批次。

## 请求和任务校验

权限由后端检查，不依赖隐藏前端按钮。列表、预览、提交、详情、重试、取消、验证码和下载分别校验范围；不能通过修改查询参数、记录 ID、组 ID 或批次 ID 越权。

后台执行前再次校验操作者、登录版本、AWS 绑定、母号配置、代理和记录身份。撤销登录或绑定、停用用户或配置变化会阻止后续处理；远程写入已经开始且结果不明确时，保留检查点并进入待核对，不把未知结果当作失败重放。

自定义 AI 地址通过公网 HTTPS 和 DNS / 连接地址校验限制服务器端请求范围。子用户不能通过该入口调用服务器内网服务。API 返回固定错误代码，不转发服务商错误正文。

## 凭据与导出

密码、AWS 凭据、代理认证、AI 密钥和短期认证结果使用应用 Fernet 密钥加密。平台登录密码使用 bcrypt；会话与 CSRF 校验独立于 AWS 登录。

进度与审计不得包含明文密码、完整 Token、Cookie 或服务商密钥。JSON 和登录信息本身属于敏感数据，只通过有权限的接口返回；请自行保管下载文件。

Token 下载有有效期，并检查真实账号映射和 Token 是否过期。完成下载后清理该任务的短期结果；重试、取消和过期也遵守清理规则。永久密码经 AWS 确认后保存在对应 SSO 记录中，不因 Token 下载而删除。

数据库、应用密钥与备份只应由服务账户和运维人员读取。能直接读取服务器文件及解密密钥的人员具有运维级访问能力；平台用户隔离不替代服务器访问控制。

## 公开源码

禁止提交实际 `.env`、数据库、密钥、账号导出、HAR、备份、真实截图或私人聊天与部署记录。提交前检查当前文件及准备公开的 Git 历史；删除当前文件不能消除旧提交中的敏感内容。

测试使用明确的合成凭据和模拟服务。真实账号验证应单独取得授权，限制费用和变更范围，保留所需结果并清理临时产物。
